# Telco costumer churn - MLOps pipeline

Progetto di previsione churn clienti con pipeline MLOps completa:
versioning dati (DVC), training riproducibile, containerizzazione (Docker), 
CI/CD (GitHub Actions), deploy come API.

## Dataset
Telco Customer Churn (Kaggle, by BlastChar), ~7000 clienti, target binario Churn (Yes/No).
